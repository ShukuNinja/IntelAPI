# Evidence

## Responsibility
Immutable execution snapshots and traceable evidence.

## Rules
- Read `docs/SOURCE_OF_TRUTH.md` and relevant sections of `docs/TECHNICAL_DESIGN.md`.
- Implement public service interfaces before route handlers.
- Add unit tests for deterministic logic and contract tests for public routes.
- Do not import private helpers from other modules.
- Update shared contracts before changing external behavior.
